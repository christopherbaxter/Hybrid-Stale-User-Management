# Security Policy

## Reporting a security concern

Please do not disclose security vulnerabilities, organisational information,
tenant details, domain names, server names, account identifiers, credentials,
access tokens or customer information through a public GitHub issue.

If you identify a security concern in this example framework, report only the
minimum technical information required to explain the problem.

## Do not include

- Real user principal names
- Email addresses
- Active Directory domain names
- Microsoft Entra tenant IDs
- Object GUIDs from a real environment
- Server or domain-controller names
- Access tokens or refresh tokens
- Passwords or temporary passwords
- Certificates or private keys
- PowerShell transcripts
- Production reports
- Screenshots containing organisational information

## Scope

This repository contains an educational, report-only PowerShell framework.

The example has been statically reviewed but has not been tested against a
live Active Directory forest or Microsoft Entra tenant. Test all changes in
an isolated non-production environment.
